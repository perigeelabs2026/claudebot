# Source audit

When you save a research report or findings file:

1. List every source URL you actually read, once each.
2. For each, say in a few words what it supported.
3. End the file with exactly one line in this form:
   `Source audit: N sources read, M claims, every claim cited.`
   If any claim lacks a source, say `Source audit: N sources read, M claims, K uncited.` and name them above.

Do not count sources you did not open. Do not invent URLs.
